# Scoring Explanations and Disclaimers

## 1. Dynamic Explanation Generation

Every threat assessment generated by `ThreatAssessmentService` dynamically compiles transparent, human-readable explanations derived from real contributing factors.

### Severity Explanation Format:
```
Severity assessed as LOW (Score: 30/100). Factors: Baseline rule severity 'LOW' (30 pts); Standard authentication failure telemetry.
```

### Confidence Explanation Format:
```
Confidence calculated as VERY_HIGH (Score: 100/100). Positive factors: Explicit predicate match verified (1 conditions: 100 pts); Schema and data integrity verified (100 pts); Registered active collector source (100 pts); Verified provenance 'CONTROLLED_TEST' (100 pts); Valid decoy session context (100 pts); Accurate UTC timestamp within clock tolerances (100 pts). Note: Score reflects evidence reliability, not real-world compromise probability.
```

## 2. Mandatory Disclaimers
1. **Zero Real-World Compromise Claims**:
   - Deception telemetry originates from isolated decoys. An interaction proves decoy engagement, never compromise of production assets.
2. **Attribution Boundaries**:
   - Confidence reflects evidence integrity, not attribution probability regarding the entity controlling the source IP address.
