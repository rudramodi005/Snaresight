# Forensic Event Detail Inspection

## Overview
Selecting any event row in the Security Events table opens the **Forensic Event Detail Drawer**, providing a comprehensive, 6-tab inspection view.

---

## Drawer Structure

### Tab 1: Overview
Presents key normalized telemetry attributes:
- **Event Identifier:** UUID primary key.
- **Observed Timestamp:** UTC storage presented in readable analyst time.
- **Category & Type:** Functional taxonomy classification.
- **Sensor Deployment:** Decoy ID, listening port, and protocol.
- **Source Context:** Observed source IP and source port.
- **Outcome:** Technical result (`SUCCESS`, `FAILURE`, `BLOCKED`, `ERROR`).
- **Review Status:** Analyst triage flag (`UNREVIEWED`, `UNDER_REVIEW`, `REVIEWED`, `ESCALATED`, `DISMISSED`).
- **Associated Investigation:** Direct link to campaign cluster if assigned.

### Tab 2: Normalized Payload (Zero Credential Storage Guarantee)
Presents the sanitized JSON metadata and payload captured by the honeypot:
- Sensitive credential fields (`password`, `auth_token`, `secret`, `private_key`) are dynamically scrubbed and replaced with `"[REDACTED_CREDENTIAL]"`.
- Formatted in an interactive, copy-friendly JSON code viewer.

### Tab 3: Relationships
Displays clickable relationship pills linking the event to:
- Raw Event telemetry.
- Correlated Activity Session.
- Observed Source Profile.
- Security Alerts generated by detection rules.
- Multi-session Behavioral Sequences.
- Campaign Investigation Clusters.
- MITRE ATT&CK Techniques.

### Tab 4: Session Timeline
Renders a chronological sequence of events belonging to the same visitor interaction session, marking the current event with a distinctive highlight.

### Tab 5: Provenance & History
Documents the complete lifecycle of the event from collection to persistence:
- `INGESTION`: Time raw packet arrived at collector.
- `VALIDATION`: Schema compliance and format verification.
- `NORMALIZATION`: Standard schema conversion.
- `DEDUPLICATION`: SHA-256 fingerprint verification against `deduplication_reference`.
- `DETECTION`: Timestamp of rule evaluation and alert triggering.

### Tab 6: Analyst Actions & Audit Trail
Allows authorized investigators to:
1. Attach an immutable analyst note.
2. Update the event review status.
3. Link the event to an existing Campaign Investigation cluster.
4. Review the complete chronological log of all historical analyst actions.
