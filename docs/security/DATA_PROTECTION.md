# SnareSight: Data Protection, Privacy & Forensic Retention Policy
**Document ID:** SEC-004  
**Status:** Approved Data Protection Policy  

---

## 1. Sensitive Data Handling & Credential Redaction

Because honeypots attract real interaction data, adversaries frequently input legitimate credentials, corporate usernames, or sensitive strings during brute-force attempts:

* **Credential Redaction Rule:** Plaintext passwords captured by decoys are **never stored** in the database, printed to console logs, or transmitted to the frontend.
* **Hash-Based Fingerprinting:** When an authentication attempt occurs:
  1. The decoy forwarder intercepts the submitted `password`.
  2. The forwarder computes an irreversible `SHA-256` hash and records the string character length.
  3. The raw plaintext password is wiped from memory using zero-fill buffer overwrites.
  4. The normalized event records only `{ "password_hash": "...", "password_length": 8 }`.
  5. The SOC dashboard displays `pass******** (8 chars)` with a copyable hash for dictionary comparison.

---

## 2. Forensic Data Provenance

To ensure absolute auditability and prevent legal or analytical confusion:
* Every database row in `raw_events`, `security_events`, and `alerts` includes a mandatory `provenance` attribute:
  * `live_honeypot`: Interaction captured from active decoy service.
  * `synthetic_demo`: Seeded mock event for UI demonstration.
  * `controlled_simulation`: Generated by automated test harnesses.
* The frontend prominently renders visual badges on every card, graph, and table cell reflecting this provenance.

## 3. Data Retention & Archival Policies

| Data Tier | Entity / Table | Retention Period | Purge Mechanism |
| :--- | :--- | :--- | :--- |
| **High-Volume Raw Telemetry** | `raw_events` | 90 Days | Scheduled database vacuum & partitioned table drop |
| **Normalized Security Events** | `security_events` | 180 Days | Soft-archive flag (`is_archived = True`) |
| **Correlated Alerts & Chains** | `alerts`, `attack_chains` | 365 Days | Retained for historical trend analysis |
| **Investigation Cases & Notes** | `investigations`, `notes` | Permanent | Retained indefinitely as case history |
| **Administrative Audit Logs** | `audit_logs` | Permanent | Immutable append-only audit trail |
