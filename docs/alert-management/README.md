## 1. Overview & Purpose

The **SnareSight SOC Alert Management and Triage Center** provides security analysts with an auditable, high-fidelity operational workspace for managing, triaging, and investigating honeypot threat detections.

Rather than treating alerts as opaque triggers or fabricating metrics, the Alert Center:
- Ingests real detection findings generated by deterministic rules (P17–P20) and correlation sequences (P21–P24).
- Maintains strict **separation between Severity (inherent impact), Confidence (analytical certainty), and Priority (operational urgency)**.
- Implements an immutable, append-only **Triage Lifecycle (`NEW` → `ACKNOWLEDGED` → `INVESTIGATING` → `ESCALATED` → `RESOLVED` → `CLOSED`)**.
- Enforces evidence-based investigation linking, allowing one-click drill-down from alerts into the **Security Events Explorer (`/events?event_id=...`)**, Session Explorer (`/sessions`), and MITRE ATT&CK Matrix (`/mitre`).
- Records every analyst action, note, status transition, and disposition in tamper-evident audit tables (`alert_audit_logs`, `alert_notes`).
- Publishes real-time alert notifications and lifecycle transitions over authenticated Server-Sent Events (SSE).

## 3. Quick Start & Navigation

1. **Access the Web Workspace:**
   - URL: `http://localhost:5173/alerts`
   - Persistent Navigation: Click **"Alert Management"** (🚨) in the SnareSight sidebar.
2. **Review Triage Summary:**
   - Inspect the real-time summary cards (New, Acknowledged, Investigating, Escalated, Resolved, Closed).
   - Click any card to instantly filter the queue by that status.
3. **Inspect Alert Details:**
   - Click any alert row to slide open the forensic detail drawer.
   - Inspect detection conditions, supporting events, and prioritization component breakdown.
4. **Execute Triage Action:**
   - Acknowledge, assign to an analyst, escalate to Tier 2, or resolve with mandatory justification.
