## Architectural Components

### 1. `ClusteringEngine`
- **Location:** `backend/app/modules/campaign_intelligence/clustering_engine.py`
- **Role:** Idempotent engine that evaluates unclustered or updated candidate entities (sessions, source profiles, behavioral sequences, and alerts) against correlation criteria.
- **Criteria Evaluated:**
  - Identical attack infrastructure or source IP addresses.
  - Overlapping behavioral sequences targeting common honeypot services.
  - Temporally correlated bursts of malicious activity across multiple honeypot sensors.
  - Matching probe signatures (e.g., identical HTTP User-Agent strings, uncommon SSH client identifiers, credential patterns).

### 2. `RelationshipScorer`
- **Location:** `backend/app/modules/campaign_intelligence/scoring.py`
- **Role:** Computes transparent, explainable relationship confidence scores (0.0 to 1.0) and classifications (`UNCONFIRMED`, `LOW`, `MODERATE`, `STRONG`, `HIGH`).
- **Signal Aggregation:**
  - Evaluates weighted correlation signals: shared target honeypot, matching command signatures, synchronized timing, shared source profile, common MITRE technique progression.
  - Applies contradiction penalties (e.g., disparate geography, conflicting protocols, out-of-order sequences).
  - Explicitly decouples relationship confidence from underlying event severity.

### 3. `ClusterLifecycleManager`
- **Location:** `backend/app/modules/campaign_intelligence/lifecycle.py`
- **Role:** Enforces valid state machine transitions:
  - `CANDIDATE` -> `UNDER_REVIEW`, `ACTIVE`, `DISMISSED`, `MERGED`
  - `UNDER_REVIEW` -> `ACTIVE`, `MONITORING`, `DISMISSED`, `MERGED`
  - `ACTIVE` -> `UNDER_REVIEW`, `MONITORING`, `CLOSED`, `MERGED`, `SPLIT`
  - `MONITORING` -> `ACTIVE`, `CLOSED`, `MERGED`
  - `CLOSED` -> `ACTIVE` (reopening upon new evidence)
  - `DISMISSED` -> `UNDER_REVIEW` (reconsidering upon new evidence)
  - `MERGED` -> Terminal (historical reference preserved)
  - `SPLIT` -> Terminal (historical reference preserved)
- **Audit Logging:** Every state transition automatically writes a non-repudiable audit entry to `cluster_audit_logs`.

### 4. `InvestigationTimelineBuilder`
- **Location:** `backend/app/modules/campaign_intelligence/timeline.py`
- **Role:** Synthesizes events, sessions, detections, and analyst reviews from all member entities into a single, unified, chronological investigation timeline with precise microsecond ordering.

### 5. `CampaignIntelligenceService`
- **Location:** `backend/app/modules/campaign_intelligence/service.py`
- **Role:** Central application service facade providing query filtering, cluster creation, entity association, analyst reviews, non-destructive merges, splits, and SSE notification dispatch.
