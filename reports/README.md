# SnareSight: Generated Reports & Audit Artifacts

---

## 1. Overview
This directory stores generated incident reports, IOC export packages, and compliance audit summaries.

---

## 2. Retention & Exclusion
> [!NOTE]
> All generated reports (*.pdf, *.json, *.csv) are ignored by `.gitignore` to prevent committing forensic incident evidence or sensitive timestamps into Git.
