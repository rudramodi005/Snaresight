# SnareSight: Security Simulation Subsystem
### Controlled Attack Generators & Reproducible Test Harnesses

---

## 1. Overview
The `simulation` directory contains offline, reproducible attack scenarios and baseline telemetry fixtures used to validate the threat detection engine, correlation pipelines, and SOC visualizers without needing live adversary interaction.

---

## 2. Directory Structure
```
simulation/
├── scenarios/     # Scripted attack sequences (brute-force bursts, path enumeration)
├── fixtures/      # Static JSON baseline telemetry and sample decoy hits
└── tests/         # Simulation validation tests
```

---

## 3. Provenance Policy
All events generated by tools in this directory are permanently stamped with `provenance: controlled_simulation` or `provenance: synthetic_demo`.
